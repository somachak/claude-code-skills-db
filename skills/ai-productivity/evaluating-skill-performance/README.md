# Skill Performance Evaluator

**Category:** ai-productivity · **Priority:** supporting · **Audience:** full-stack

Measures whether a Claude skill actually helps: paired with-skill vs baseline runs spawned together, objective assertions for verifiable outputs and human judgment for subjective ones, transcript review for wasted work, and a 20-query trigger eval set (near-miss negatives included) for optimizing the description field that controls invocation. Use when a skill has been written but never measured, when iterating on a skill that fires inconsistently or not at all, or when deciding whether a change to a skill body was actually an improvement.

## When Claude should reach for this

Trigger phrases: `evaluate a skill`, `skill evals`, `skill not triggering`, `benchmark a skill`, `optimize skill description`, `test my skill`
