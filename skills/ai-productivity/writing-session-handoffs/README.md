# Session Handoffs Between Claude Agents

**Category:** ai-productivity · **Priority:** supporting · **Audience:** back-end, front-end, full-stack

Compacts a long Claude session into a handoff document the next agent (or your future self) can resume from cleanly. Use when ending a long pairing session, switching from research to implementation, splitting work across subagents, or when context is filling up and you need to checkpoint before the model loses the early decisions.

## When Claude should reach for this

Trigger phrases: `handoff doc`, `session handoff`, `compact context`, `resume later`, `agent handoff`, `checkpoint conversation`
