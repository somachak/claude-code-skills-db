# Implementing Next.js Cache Components

**Category:** frontend · **Priority:** supporting · **Audience:** full-stack

Implements Next.js Cache Components and Partial Prerendering (PPR): the 'use cache' directive, cacheLife() lifetimes, cacheTag() tagging, updateTag()/revalidateTag() invalidation, and static-shell vs streaming-dynamic composition. Use when a Next.js 15/16 project has cacheComponents enabled, when deciding what to cache vs stream through Suspense, or when replacing deprecated segment config like `export const revalidate`.
