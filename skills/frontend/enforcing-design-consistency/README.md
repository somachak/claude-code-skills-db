# Design Lock & Consistency Gate

**Category:** frontend · **Priority:** supporting · **Audience:** front-end, full-stack

Keeps AI-built UIs looking designed across screens and sessions: lock design decisions (accent, type scale, spacing, radius, motion) in a committed DESIGN.md with tokens-only enforcement, ban the nameable tells of AI-generated UI (default indigo, emoji icons, even card grids, pure-black backgrounds), and run a score-then-fix loop with rendered visual verification before any screen ships. Use when UI drifts between pages, when output 'looks AI-generated', or when starting a project that must stay visually coherent without a design team.
